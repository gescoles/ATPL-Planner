Conectar con Supabase

1. Crea un proyecto en supabase.com (o usa uno que ya tengas).
2. En el SQL Editor pega y ejecuta el script supabase-schema.sql que te he dado aparte.
3. Ve a Project Settings → API y copia la Project URL y la clave anon public aquí abajo.

cumplido por debajo por encima sin registrar
250Q/día hasta el 31/8, 200Q/día desde el 1/9 — siempre enteras en UNA asignatura a la vez, por este orden: Meteo → POF → FPL → Air Law → Performance. en cuanto terminas una, la siguiente empieza a recibir la capacidad del día. lo que no cumplas un día se suma a los días siguientes de esa misma asignatura (y si haces de más, se descuenta también).

se guarda siempre en este navegador (localStorage), y si conectas Supabase (⚙ arriba), además se sincroniza en la nube — así lo tienes accesible desde cualquier dispositivo y a salvo aunque borres el navegador.
